# Support

OpenClaw Quick Replies is discontinued. New features, compatibility updates, bug fixes, and installation support are no longer provided.

Use OpenClaw 2026.8.1 or newer and its native [`ask_user`](https://docs.openclaw.ai/tools/ask-user) structured questions. General OpenClaw installation, model, provider, and channel questions belong in the official OpenClaw documentation and community support channels.

The immutable [v0.1.6 source tree](https://github.com/goldmar/openclaw-quick-replies/tree/v0.1.6) retains the former installation, configuration, architecture, and troubleshooting documentation for historical reference and forks.
